# Get help

Read the [README](README.md) and [contribution guide](CONTRIBUTING.md) for setup and development instructions.
For usage questions, use [PistonMOTD Discord](https://discord.gg/FZtaMpuvj8).

For a reproducible defect or feature request, use [the issue tracker](https://github.com/AlexProgrammerDE/PistonMOTD/issues).
Name the repository and affected version in reports sent to a shared tracker.
Search existing reports before opening another issue. Add new evidence to an existing report when it covers the same problem.

## Details that help

PistonMOTD build, server/proxy implementation and version, client and Java versions, placeholder integrations, and redacted configuration.

Include the failing step, expected result, actual result, and a minimal reproduction.
Use text for logs and commands. Use screenshots for visible problems.
Remove credentials, cookies, webhook URLs, personal data, and private infrastructure details.

For security concerns, read [the security reporting instructions](SECURITY.md).
